Interface React (Vite) do TCC de extração para PJe-Calc.

Comandos na pasta `frontend`:

```bash
npm install
npm run dev -- --host 127.0.0.1 --port 4174
```

A API precisa estar em `http://127.0.0.1:8765`. O Vite faz proxy de `/api` e `/health`.

Contexto do projeto: [AGENTS.md](../AGENTS.md) na raiz.
